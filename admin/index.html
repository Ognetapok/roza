Ключ доступа

Нужен только для сохранения: это токен GitHub с правом записи в репозиторий. Хранится в этом браузере, на сайт не уходит.

Где взять токен
  1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → roza.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Скопировать токен и вставить сюда.
